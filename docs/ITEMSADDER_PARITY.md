# Feature Catalog and ItemsAdder Parity

CatItems remains an independent plugin. This document records which broad
custom-content groups are live, which have foundations, and which are planned.
The same catalog is available through `/catitems features` and the public API.

## Live

- YAML custom items
- stable CustomModelData allocation and PDC identity
- modern item-model files on Minecraft 1.21.4+
- legacy overrides on Minecraft 1.21 through 1.21.3
- resource-pack build with SHA-1
- self-host, external URL, or disabled delivery
- automatic join delivery
- MiniMessage/RGB names and lore
- glint override, starter assets, service API, and administration commands

## Foundation

- queryable feature catalog
- pack overlay target structure
- production, proxy, and hashing hardening

## Planned

- custom blocks, furniture, entities, and animations
- recipes, fuels, sounds, music discs, fonts, emojis, HUDs, and GUIs
- armor geometry, hats, wings, consumables, durability, and projectiles
- crops, loot, advancements, tags, liquids, vehicles, and world generation
- scripting, WorldEdit, and third-party plugin hooks

## Boundary

The catalog does not activate complex unfinished mechanics. It exposes an
auditable roadmap to administrators and other plugins without claiming that
planned modules are already available.
