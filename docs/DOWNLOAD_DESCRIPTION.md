# CatItems 0.2.1 Alpha

CatItems is a standalone custom-item and resource-pack engine for Paper 1.21.x.
Define namespaced items in YAML, keep their identity stable through PDC data,
and let CatItems assign persistent model data and build the correct pack for the
running Minecraft version.

The plugin supports modern item-model definitions, legacy model overrides,
MiniMessage/RGB names and lore, automatic ZIP and SHA-1 creation, external pack
URLs, optional self-hosting, automatic join delivery, diagnostics, and a public
Bukkit service API. Four starter items and compact 3D models are included.

CatItems has no plugin dependencies. It can be used by itself or as an optional
visual foundation for plugins such as CatDrugs.

## Requirements

- Java 21
- Paper 1.21 through 1.21.11

## Important

This is an Alpha build. Back up your server, verify the generated resource pack,
and test the public URL, firewall, and reverse-proxy configuration before
production. Replace the JAR only while the server is stopped.
